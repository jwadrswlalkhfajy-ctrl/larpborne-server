# Larpborne Online — ملفات السيرفر

المجلد يحتوي على:
- `index.html`: نسخة اللعبة التي تم ربطها مسبقاً بعميل WebSocket.
- `server.js`: سيرفر Node.js يدعم الغرف (حد أقصى 4 لاعبين)، الحركة، الشات، الضرر بين اللاعبين، مزامنة ضربات الزعماء، الأصدقاء، وحفظ تقدم كل لاعب بالاسم.
- `package.json`: إعدادات التشغيل.

## تشغيل محلي
1. ثبّت Node.js 20 أو أحدث.
2. افتح الطرفية داخل المجلد.
3. نفّذ `npm install` ثم `npm start`.
4. عنوان WebSocket محلياً: `ws://localhost:10000`.

## النشر على Render
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. أنشئ Web Service واربط المستودع.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. بعد النشر استخدم عنوان `wss://YOUR-SERVICE.onrender.com` في خانة عنوان السيرفر داخل اللعبة.

## ملاحظة حفظ البيانات
السيرفر يكتب ملفات الحفظ داخل `data/saves.json`. أنظمة الملفات في الاستضافات المجانية قد تكون مؤقتة؛ للحصول على حفظ دائم على Render اربط Persistent Disk أو قاعدة بيانات خارجية، واجعل `DATA_DIR` يشير إلى مسار القرص الدائم.

## ملاحظة عن النسخة الأولية
هذه نسخة أولية قابلة للاختبار وليست نظام حسابات آمن: أسماء اللاعبين ليست توثيق هوية، وقائمة الأصدقاء مرتبطة باسم اللاعب. اختبرها مع أصدقائك قبل نشرها للعامة.
